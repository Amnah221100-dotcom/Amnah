# TACTICA AI Delivery Roadmap

- Application shell and design system
- Arabic/English RTL/LTR
- Authentication/RBAC foundation
- Command Center
- MapLibre 2D map and layer manager
- Drawing & Measurement
- Buffer and Fixed-Size Box
- AOI, Cases, Evidence

- Smart Alerts
- Period comparison and timeline
- Smart Guide foundation
- TACTICA Copilot foundation
- Quick Reports, Production foundation, QC foundation

## V2 — Geospatial Intelligence
- PostgreSQL/PostGIS backend
- Object storage and metadata catalog
- GeoJSON/KML/CSV/GeoTIFF workflows
- Optical indices and multi-date comparison
- Terrain/DEM processing
- SAR analysis workflows
- Detection result layers and confidence review
- 3D Digital Twin and 2D↔3D sync
- Maritime/Aviation feed adapters for authorized data
- GNSS integrity/anomaly workspace
- Data Health, backups and scheduled updates

## V3 — Intelligence Engine
- Multi-source spatial/temporal fusion
- Pattern of Life and anomaly engine
- Knowledge/Evidence Graph
- Entity resolution
- Hypothesis Board
- Intelligence Gaps
- Contradiction detector
- Similar-case search
- Living Intelligence Twin
- Intelligence Time Travel
- Counter-Evidence AI
- Explainability and provenance

## V4 — Production & Governance
- Production Queue and Product Composer
- Full bilingual report-template library
- Automated Quick Intelligence Brief
- Data/Imagery/Map/Analysis/Evidence/Report QC
- Analyst Review and Supervisor Approval
- Print/Email/Export/Library dissemination
- Version comparison and restore points
- Collaboration and audit dashboards
